# 硕士毕业设计创新点规划

## 研究背景

- **方向**：图像超分辨率（Image Super-Resolution）
- **Baseline**：MambaIRv2（CVPR 2025）
- **核心技术**：状态空间模型（SSM）、ASSM 注意力机制、非因果建模
- **研究动机**：MambaIRv2 通过非因果注意力状态空间模块（ASSM）实现了线性复杂度的全局感受野，在经典超分、轻量超分和真实去噪等任务上取得了优异性能。然而，该方法在高频纹理捕获、退化自适应和局部精细建模三方面仍有提升空间。本规划围绕这三点提出三个相互独立、各有侧重的创新方案。

## 创新点一：多尺度频域感知 MambaIRv2（MFAMambaIR）

### 1.1 动机

现有 MambaIRv2 主要在空间域进行特征建模，对高频纹理细节的捕获能力有限。图像超分的核心难点之一正是恢复高频成分——边缘锐度、细密纹理（如草地、建筑细节、文字笔画）往往是衡量视觉质量的关键因素。

频域信息（如小波分解的高频子带 LH/HL/HH 或 FFT 幅度谱）天然包含边缘和纹理先验，且这些先验在不同尺度上呈现规律性的分布。将频域感知引入 MambaIRv2 的非因果 SSM 框架，可以在不破坏线性复杂度优势的前提下，为模型提供额外的频率维度监督信号，使其在扫描序列中同时关注空间结构与频率成分。

此外，MambaIRv2 的语义引导邻域机制（Semantic-Guided Neighborhood）主要在空间特征上计算相似度；将其拓展到频域后，可以建立"频率相似"像素之间的联系，对周期性纹理（如砖墙、栅栏、织物纹路）的恢复尤为有益。

### 1.2 核心思路

在 MambaIRv2 的 ASSM 模块前插入频域分支，通过离散小波变换（DWT）或快速傅里叶变换（FFT）获取多尺度频域成分。设计**频域感知门机制（Frequency-Aware Gate, FAG）**与 ASSM 互补融合，使模型在非因果扫描序列中同时捕捉频域高频细节与空间结构信息。

整体结构可概括为：

```
输入特征 F_in
    ├── 空间分支 → F_spatial（原有路径）
    └── 频域分支 → DWT/FFT → F_freq
          ↓
    频域-空域融合门（FSG）
          ↓
    F_fused → ASSM → 非因果建模输出
```

### 1.3 技术方案

#### 1.3.1 频域特征提取

- **离散小波变换（DWT）方案**：
  - 对输入特征图 F ∈ R^{C×H×W} 执行 2D Haar 小波变换，分解为四个子带：
    - LL（低频近似）：保留整体结构
    - LH（水平高频）：捕捉水平边缘
    - HL（垂直高频）：捕捉垂直边缘
    - HH（对角高频）：捕捉角点与细纹理
  - 对 LL 子带递归执行第二层 DWT，形成两级多尺度分解
  - 各子带经 1×1 Conv 调整通道维度后拼接：F_freq = Concat(LL₂, LH₁, HL₁, HH₁, LH₂, HL₂, HH₂)

- **快速傅里叶变换（FFT）方案（备选）**：
  - F_freq = FFT2D(F)，取幅度谱 |F_freq| 与相位谱 ∠F_freq
  - 对幅度谱施加可学习的频率滤波器（高频增强、低频抑制）
  - IFFT2D 重构回空间域，得到频域增强特征

#### 1.3.2 频域-空域融合门（FSG）

设计自适应门机制，让网络逐像素决定融合比例：

```
Gate = σ(Conv_{3×3}(Concat(F_spatial, F_freq)))   # σ 为 Sigmoid 激活
F_fused = Gate ⊙ F_freq + (1 - Gate) ⊙ F_spatial
```

其中 ⊙ 为逐元素乘法。Gate 值趋近 1 时偏向频域特征（纹理丰富区域），趋近 0 时偏向空间特征（平坦区域）。

可选进阶：引入 **Channel Attention** 增强版 FSG：

```
CA_freq = SE_Block(F_freq)       # 通道注意力
CA_spatial = SE_Block(F_spatial)
Gate = σ(Linear(CA_freq ⊕ CA_spatial))
```

#### 1.3.3 与 ASSM 集成

- F_fused 作为 ASSM 的输入，进入非因果扫描序列进行全局建模
- ASSM 输出的全局特征与原始空间特征做残差连接：F_out = F_in + ASSM(F_fused)
- 每个 Residual State Space Block（RVSSM）中均插入 FSG，形成"频域感知 RVSSM"

#### 1.3.4 频域相似度扩展

将 MambaIRv2 的语义引导邻域机制扩展到频域：

- 在频域特征 F_freq 上计算像素对相似度：S_freq(i,j) = cos(F_freq[i], F_freq[j])
- 与空间域相似度加权融合：S_total = α·S_spatial + (1-α)·S_freq，其中 α 可学习
- 使非因果扫描在处理周期性纹理时能建立频率相似像素间的联系

#### 1.3.5 频域辅助损失

在训练时引入频域监督信号：

```
L_freq = L1(DWT(SR), DWT(HR))   # 小波域损失
L_total = L_pixel + λ_freq · L_freq
```

λ_freq 控制频域损失权重，实验证明可进一步促进高频恢复。

#### 1.3.6 RFA级联融合增强

借鉴 UniConvNet（ICCV 2025）的三层感受野聚合器（Receptive Field Aggregator, RFA）设计思想，对频域-空域融合门（FSG）进行级联增强，形成**级联频域融合门（Cascaded FSG, CFSG）**。

**核心思想**：

UniConvNet 的 RFA 通过三层级联的 Amp（放大）+ Dis（判别）模块逐步扩大有效感受野，每一层放大前层影响权重、判别新尺度信息，并通过 AGD（Adaptive Gradient Distribution）约束保持权重分布合理性。将这一思想引入 MFAMambaIR 的频域-空域融合，可以显著提升融合门对多尺度频域信息的捕获能力。

**设计方案**：

1. **Amp（放大）模块引入 FSG**：
   - 原 FSG 仅使用单层 3×3 卷积生成门控权重，感受野有限
   - 引入 Amp 分支：使用大核深度卷积（7×7 → 9×9 → 11×11 逐级扩大）放大空域特征的影响范围
   - Amp 分支使融合门在决策时能感知更大空间上下文，对大范围纹理恢复尤为重要

2. **Dis（判别）模块引入 FSG**：
   - Dis 分支使用小核卷积（3×3）精细判别频域特征的细节信息
   - 与 Amp 分支形成"粗-细"互补：Amp 负责全局上下文感知，Dis 负责局部频域细节判别
   - 两分支通过门控权重自适应融合

3. **级联频域融合门（Cascaded FSG）**：
   - 将单层 FSG 替换为三级级联结构，每级包含独立的 Amp + Dis 模块
   - 三级核大小渐进扩大：Stage1(7×7) → Stage2(9×9) → Stage3(11×11)
   - 前一级的融合输出作为后一级的空域输入，频域输入保持不变，实现逐级放大与判别
   - 最终输出通过残差连接回原始空域特征

```
级联融合流程：
  Stage1: fused₁ = Amp₇×₇(F_spatial) ⊕ Dis₃×₃(F_freq) → Gate₁ → F₁
  Stage2: fused₂ = Amp₉×₉(F₁) ⊕ Dis₃×₃(F_freq) → Gate₂ → F₂
  Stage3: fused₃ = Amp₁₁×₁₁(F₂) ⊕ Dis₃×₃(F_freq) → Gate₃ → F₃
  输出: F_out = F_spatial + scale · F₃    （残差连接 + 可学习缩放）
```

4. **AGD 约束**：
   - 引入 Adaptive Gradient Distribution 约束，确保级联过程中各级门控权重分布合理
   - 防止某一级门控权重过度主导（避免梯度集中在某一级而其他级失效）
   - 通过可学习温度参数控制门控权重的锐度，训练过程中自适应调整
   - AGD 正则化项：L_agd = Σᵢ Var(Gateᵢ)，鼓励各级门控方差保持在合理范围

**与原 FSG 的对比**：

| 特性 | 原 FSG | Cascaded FSG |
|------|--------|-------------|
| 层数 | 单层 | 三级级联 |
| 感受野 | 3×3 | 7→9→11 渐进扩大 |
| 融合策略 | 直接门控 | Amp+Dis 逐级放大判别 |
| 权重约束 | 无 | AGD 自适应约束 |
| 参数量增加 | 基准 | +2~3% |

### 1.4 预期效果

| 指标 | 预期提升 | 说明 |
|------|----------|------|
| 经典 SR（×4）PSNR | +0.15~0.25 dB | Urban100、Manga109 等高纹理数据集提升明显 |
| 经典 SR（×2）PSNR | +0.08~0.15 dB | 低倍率下频域信息增益相对较小 |
| 参数量增加 | <3% | 频域分支仅增加少量卷积参数 |
| 计算复杂度增加 | <5% | DWT/FFT 本身计算高效，门机制轻量 |
| 视觉效果 | 显著改善 | 草地、建筑细节、文字笔画等高频区域 |

### 1.5 实现计划

| 周次 | 任务 |
|------|------|
| 第 1-2 周 | 小波/FFT 模块实现，频域特征提取验证；对比 Haar、Daubechies 等小波基 |

### 1.6 潜在风险与应对

- **风险**：DWT 对特征图尺寸有 2 的幂次要求 → **应对**：使用 padding 或改用 FFT 方案
- **风险**：频域门机制导致低频区域过平滑 → **应对**：引入频域辅助损失约束
 **风险**：计算开销超预期 → **应对**：仅在部分 RVSSM 块中插入频域分支（如每隔一个块插入一次）

## 创新点二：退化感知的动态路由 MambaIRv2（DRMambaIR）

### 2.1 动机

真实世界图像退化类型多样且程度不一：模糊核尺寸差异（运动模糊、散焦模糊）、噪声水平变化（高斯噪声、真实传感器噪声）、压缩伪影（JPEG、HEVC）及其混合形式普遍存在。MambaIRv2 采用固定深度和固定结构的网络处理所有输入，对所有退化类型一视同仁，存在两方面问题：

1. **性能瓶颈**：固定结构难以针对不同退化类型采取最优处理策略，泛化性受限
2. **计算浪费**：对轻微退化图像（如仅含轻微 JPEG 压缩伪影）施加与严重退化图像（如重度模糊+高噪声）相同的完整网络深度，造成不必要的计算开销

设计退化感知机制使网络根据输入图像的退化特征**动态调整处理策略**，可在保持甚至提升性能的同时实现自适应推理效率。

### 2.2 核心思路

设计**轻量级退化估计器（Degradation Estimator, DE）**，从输入 LR 图像中提取退化表征向量。基于退化表征动态生成路由权重，选择性激活 MambaIRv2 不同层级的处理单元。对轻微退化图像走浅层快速路径，对严重退化图像走深层精细路径。

整体结构：

```
LR 图像
    ├── 退化估计器 → 退化向量 d ∈ R^C
    │       ↓
    │   动态路由器 → 路由权重 {w₁, w₂, ..., w_N}
    │       ↓
    └── MambaIRv2 Backbone（N 个 RVSSM 块）
            ↓
        加权聚合输出 → SR 图像
```

### 2.3 技术方案

#### 2.3.1 退化估计器（Degradation Estimator, DE）

**结构设计**：

```
LR 图像 (3×H×W)
    → Conv(3→32, stride=2) → LeakyReLU
    → Conv(32→64, stride=2) → LeakyReLU
    → ResBlock×2 (64ch)
    → Global Average Pooling → d ∈ R^64
```

轻量级 CNN 编码器，总参数量 <0.1M，推理时间 <1ms。

**预训练策略**（可选）：

- 使用对比学习（Contrastive Learning）预训练退化估计器：
  - 正样本对：同一退化类型/程度的图像对
  - 负样本对：不同退化类型的图像对
  - 损失：InfoNCE Loss
- 预训练后冻结 DE 参数，在主网络训练中作为条件输入
- 备选：与主网络联合端到端训练（更简单，效果可能略差）

#### 2.3.2 动态路由模块（Dynamic Router）

**路由权重生成**：

```
d ∈ R^64
    → MLP(64→128→N) → Sigmoid → {w₁, w₂, ..., w_N}
```

其中 N 为 RVSSM 块的总数，w_i ∈ [0,1] 表示第 i 个块的激活权重。

**软路由（Soft Routing）**：

```
output = Σᵢ wᵢ × Block_i(x)
```

- 所有块均参与计算，但低权重块的贡献被抑制
- 软路由可微，支持端到端梯度训练
- 训练初期可加入温度参数 τ 控制路由锐度：w_i = Sigmoid(logits_i / τ)，训练时 τ 从 1 逐渐退火至 0.1

**硬路由（Hard Routing，推理加速）**：

- 设置阈值 θ（如 0.3），低于阈值的块跳过不计算
- 推理时实际激活块数 = count(w_i > θ)，实现自适应深度
- 为保证训练稳定性，使用 Gumbel-Softmax 或 Straight-Through Estimator (STE) 近似硬路由梯度

#### 2.3.3 自适应深度机制

**早退（Early Exit）机制**：

- 在每隔 K 个 RVSSM 块后设置一个早退判断点（Exit Point）
- 判断点结构：Global Average Pooling → Linear → Sigmoid → confidence score
- 若 confidence > threshold（如 0.9），提前输出当前特征并跳过剩余块
- 最终输出为所有早退点输出的加权平均（按 confidence 加权）

**深度预算（Depth Budget）**：

- 退化估计器同时输出深度预算 B ∈ [B_min, N]，B 为整数
- 仅激活前 B 个 RVSSM 块
- B_min 为最小深度（如 N/4），确保最轻微退化也有基本处理能力

#### 2.3.4 训练策略

**多退化联合训练**：

- 训练数据混合多种退化：
  - 双三次下采样 ×2/×3/×4
  - 高斯模糊（核大小 3×3~21×21）+ 双三次下采样
  - JPEG 压缩（质量 10~95）+ 双三次下采样
  - 混合退化：模糊 + 噪声 + 压缩
- 退化标签自动生成，无需人工标注

**退化感知损失**：

```
L_total = L_recon + λ_route · L_route_reg + λ_depth · L_depth

L_route_reg = -Σᵢ wᵢ · log(wᵢ)        # 路由熵正则，防止路由坍塌
L_depth = max(0, B_active - B_target)   # 深度预算约束
```

- L_route_reg 防止所有权重趋近 0 或 1 的路由坍塌现象
- L_depth 约束平均激活深度不超过预算，保证推理效率

**渐进式训练**：

1. 第一阶段（warmup）：固定全层激活，训练主网络至收敛
2. 第二阶段：引入路由机制，联合训练路由器和主网络
3. 第三阶段：引入早退机制，微调全网络

### 2.4 预期效果

| 指标 | 预期提升 | 说明 |
|------|----------|------|
| 盲超分 PSNR | +0.2~0.4 dB | 对比固定结构 MambaIRv2 |
| 推理效率（轻退化） | 计算量减少 30~40% | 自适应深度机制跳过冗余块 |
| 推理效率（重退化） | 与原始持平 | 严重退化时激活全部块 |
| 真实图像鲁棒性 | 显著提升 | 退化感知带来泛化性增益 |
| 多任务扩展 | SR+去噪+去压缩 | 同一模型处理多种退化 |

### 2.5 实现计划

| 周次 | 任务 |
|------|------|
| 第 1-2 周 | 退化估计器设计与预训练；验证退化向量是否能区分不同退化类型 |
| 第 3-5 周 | 动态路由模块实现（软路由+硬路由）；与 MambaIRv2 集成调试 |
| 第 6-7 周 | 多退化联合训练策略调优；退化感知损失系数搜索 |
| 第 8-10 周 | 盲超分实验、消融实验（路由方式、深度预算、早退阈值）；真实图像测试 |

### 2.6 潜在风险与应对

- **风险**：路由训练不稳定，出现模式坍塌 → **应对**：路由熵正则 + warmup 训练策略
- **风险**：早退导致输出质量下降 → **应对**：设置最小深度保障 + confidence 阈值调优
- **风险**：退化估计器泛化性不足 → **应对**：增加训练退化类型多样性 + 数据增强
- **风险**：硬路由梯度近似误差 → **应对**：对比 Gumbel-Softmax 与 STE，选择更稳定方案

## 创新点三：局部-全局协同注意力增强 MambaIRv2（LGMambaIR）

### 3.1 动机

MambaIRv2 的 ASSM 通过非因果扫描实现全局感受野，能够捕获长距离依赖关系，这是其核心优势。然而，全局扫描序列在展开图像时不可避免地拉大了空间相邻像素在序列中的距离，导致对**局部精细结构**（如小尺度纹理、重复模式、规则几何边缘）的建模相对薄弱。

具体而言：
- 一块 8×8 的砖墙纹理，在光栅扫描序列中其像素间隔可达 8 步以上
- ASSM 的状态传递机制虽能保持长距离信息，但对这种短距离、高密度的局部模式，显式的局部注意力计算更为直接高效
- Transformer 架构中的窗口自注意力（Swin Transformer 的核心）正是为解决此类局部建模问题而设计

因此，引入**局部窗口注意力与全局 SSM 的协同机制**，可在保持线性复杂度优势的同时增强局部建模能力，形成"全局上下文 + 局部精细"的互补架构。

### 3.2 核心思路

设计**局部-全局协同模块（LG-Synergy Module, LGSM）**：在 ASSM 的全局非因果扫描基础上，并行引入轻量级局部窗口自注意力分支。两分支通过**交叉门控机制（Cross-Gating Fusion, CGF）**融合，全局分支提供长距离上下文，局部分支捕捉精细纹理模式。

整体结构：

```
输入特征 F_in
    ├── 全局分支 → ASSM（非因果扫描）→ F_global
    └── 局部分支 → Window Self-Attention → F_local
          ↓
    交叉门控融合（CGF）
          ↓
    F_out = CGF(F_global, F_local)
```

### 3.3 技术方案

#### 3.3.1 局部窗口注意力分支

**方案 A：轻量级窗口自注意力**

- 将特征图 F ∈ R^{C×H×W} 划分为不重叠的 w×w 窗口（w=8）
- 在每个窗口内执行多头自注意力（Multi-Head Self-Attention）：
  - 头数 = 2（轻量化设计，减少参数）
  - 每头维度 = C/2
  - 窗口内复杂度：O(w²·C)，全图复杂度：O((H·W/w²)·w²·C) = O(H·W·C)，线性
- 添加相对位置编码（Relative Position Bias）增强位置感知
- 窗口之间不交互（保持计算效率），通过后续 ASSM 分支实现跨窗口信息流动

**方案 B：深度可分离卷积替代（更轻量）**

- 使用 Depth-wise Separable Conv 替代窗口注意力：
  - Depth-wise Conv（kernel=7×7，groups=C）→ 局部空间混合
  - Point-wise Conv（1×1）→ 通道混合
- 参数量与计算量进一步降低，但表达能力略弱于注意力
- 作为消融实验的对照方案

**方案 C：可变形卷积（Deformable Conv）**

- 使用 Deformable Conv（DCNv2/v3）自适应地聚合局部信息
- 偏移量由输入特征动态预测，能关注不规则局部模式
- 计算量略高于方案 B，但灵活性更强

#### 3.3.2 全局 SSM 分支

- 保持原有 ASSM 结构不变
- 输入与局部分支相同（均为 F_in）
- 输出 F_global ∈ R^{C×H×W}

#### 3.3.3 交叉门控融合（Cross-Gating Fusion, CGF）

**基础版 CGF**：

```
G_local = σ(Linear(F_global))       # 全局信息指导局部分支的权重
G_global = σ(Linear(F_local))       # 局部信息指导全局分支的权重
F_out = G_local ⊙ F_local + G_global ⊙ F_global
```

- 全局特征通过门控增强局部特征中语义相关的纹理模式
- 局部特征通过门控增强全局特征中的精细结构信息
- 双向指导实现信息互补

**进阶版 CGF（带通道注意力）**：

```
CA_global = SE_Block(F_global)       # 全局通道注意力
CA_local = SE_Block(F_local)         # 局部通道注意力

G_local = σ(MLP(CA_global ⊕ CA_local))    # ⊕ 为拼接
G_global = σ(MLP(CA_local ⊕ CA_global))

F_out = G_local ⊙ F_local + G_global ⊙ F_global + F_in    # 残差连接
```

#### 3.3.4 层级部署策略

不同深度的网络层对不同尺度信息的敏感度不同，设计层级差异化部署：

| 网络层级 | 模块类型 | 原因 |
|----------|----------|------|
| 浅层（第 1~4 块） | 纯 ASSM | 浅层主要捕捉全局结构和大尺度特征，全局感知优先 |
| 中层（第 5~12 块） | LG-Synergy Module | 中层是纹理和细节建模的核心阶段，局部+全局协同最有效 |
| 深层（第 13~16 块） | 纯 ASSM | 深层侧重语义级建模和全局一致性，全局感知优先 |

- 中层部署 LGSM 的消融实验验证其最优性
- 备选：所有层均部署 LGSM（性能上限更高但参数增加更多）

#### 3.3.5 局部-全局特征对齐损失

训练时引入辅助损失促进两分支学习互补信息：

```
L_align = ||F_global - F_local||₂²    # 特征对齐损失（可选）
L_diversity = -||F_global - F_local||₂²  # 多样性损失（防止两分支趋同）
L_total = L_recon + λ · L_diversity
```

多样性损失鼓励两分支学习不同的特征表示，避免冗余。

|------|----------|------|

### 3.6 潜在风险与应对

- **风险**：窗口注意力与 ASSM 特征空间不兼容 → **应对**：在融合前增加投影层对齐特征空间
- **风险**：参数量增加过多 → **应对**：减小窗口注意力头数或使用深度卷积替代方案
- **风险**：局部-全局分支趋同（学习冗余特征）→ **应对**：引入多样性损失 + 正交约束
- **风险**：窗口边界出现伪影 → **应对**：使用移动窗口（Shifted Window）策略或重叠窗口

## 三个创新点之间的关系

```
MambaIRv2（Baseline）
    │
    ├── 创新点一 MFAMambaIR
    │       关注维度：频率域
    │       核心问题：高频纹理捕获不足
    │       解决思路：频域感知门机制 + RFA级联融合增强（借鉴UniConvNet）
    │
    ├── 创新点二 DRMambaIR
    │       关注维度：退化适应性
    │       核心问题：固定结构泛化性差
    │       解决思路：退化感知动态路由
    │
    └── 创新点三 LGMambaIR
            关注维度：空间尺度
            核心问题：局部精细建模薄弱
            解决思路：局部-全局协同注意力
```

三个创新点分别针对 MambaIRv2 的三个不同短板，**相互独立、可单独发表**，也可在毕设论文中作为三个并列贡献章节。若时间允许，可探索两两组合（如 MFAMambaIR + LGMambaIR）的叠加效果作为额外实验。
